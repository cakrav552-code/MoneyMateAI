# 💰 MoneyMate AI

Smart Personal Finance Assistant powered by Telegram Bot.

MoneyMate AI membantu mencatat pemasukan, pengeluaran, target tabungan, budget bulanan, serta memberikan laporan keuangan langsung melalui Telegram.

---

## ✨ Features

- ✅ AI Transaction Parser
- ✅ Record Income & Expense
- ✅ Dashboard Keuangan
- ✅ Budget Bulanan
- ✅ Target Tabungan
- ✅ Riwayat Transaksi
- ✅ Edit Transaksi
- ✅ Hapus Transaksi
- ✅ Laporan Harian
- ✅ Scheduler Otomatis

---

## 🚀 Installation

Clone repository

```bash
git clone https://github.com/cakrav552-code/MoneyMateAI.git
```

Masuk ke folder project

```bash
cd MoneyMateAI
```

Install dependency

```bash
pip install -r requirements.txt
```

Jalankan bot

```bash
python main.py
```

---

## 🤖 Commands

| Command | Function |
|----------|----------|
| /start | Memulai bot |
| /saldo | Melihat saldo |
| /dashboard | Dashboard keuangan |
| /laporan | Laporan hari ini |
| /budget | Mengatur budget |
| /target | Mengatur target tabungan |
| /riwayat | Riwayat transaksi |
| /edit | Edit transaksi |
| /hapus | Hapus transaksi |
